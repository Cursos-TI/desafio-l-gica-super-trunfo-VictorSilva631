Prezado Avaliador,
Este projeto em .C simula o jogo Super Trunfo com cartas de cidades, dividido em três níveis: **Novato**, **Aventureiro** e **Mestre**.

## Objetivo
Comparar cartas de cidades com base em atributos como população, área, PIB e pontos turísticos.

##  Nível Novato
- Cadastro de duas cidades via terminal (`scanf`)
- Exibição dos dados das cartas
- Comparação direta com `if` e `if-else` de um único atributo (ex: população)

##  Nível Aventureiro
- Menu interativo (`switch`) para escolha de atributo
- Lógica de comparação aprimorada com menu de seleção

##  Nível Mestre
- Permite escolher **dois atributos** para desempate
- Implementa **operador ternário** (condição)
- Calcula densidade populacional (população / área)
- Trata empates entre cidades
